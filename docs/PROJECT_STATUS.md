# 项目状态与未完成事项

- 更新日期：2026-09-30
- 项目阶段：单目 RGB 室内目标检测研究与基准对比
- 当前状态：按用户要求暂停，训练进程已停止

## 项目实现目标

VisionNav 面向人工智能专业学生，通过可复现实验学习目标检测、数据处理、模型评估和机器人视觉。近期目标是在 Robot@Home2 室内 RGB 图像上建立可信的跨住宅泛化基线；中期计划接入仿真机器人；之后再评估低成本双目模组和实体机器人。项目尚未达到机器人部署或安全决策所需的可靠性。

## 已完成

- 在项目本地 Conda 环境中搭建 Python、PyTorch CUDA、OpenCV 和 Ultralytics 工具链，完成公开图片推理 Demo。
- 建立 VOC 公开数据集训练与评估流程，并形成初始通用检测基准。
- 实现 Robot@Home2 RGB/实例 mask 数据读取、YOLO 检测框导出、标签/数据划分审计和训练评估工具。
- 整理四个开发住宅 `alma`、`anto`、`pare`、`rx2` 的 candidate-v3 数据：11,170 张图像，包括正样本与按住宅/房间抽取的目标缺席帧；类别为 `bottle`、`chair`、`table`。
- 完成 640 输入的四折 LOHO 训练、独立验证、跨住宅平均和小目标数据审计。四折验证不包含 `sarmis`。
- 为错误审计器增加 v3 `val.txt`/共享标签目录支持，并兼容旧式逐折目录。两种布局均完成路径与标签预检；相关代码在提交前已通过语法检查与小样本路径验证。

|---|---:|
| Precision | 0.3488 |
| Recall | 0.2571 |
| mAP50 | 0.2125 |
| mAP50–95 | 0.1114 |

低召回和瓶子漏检仍是主要弱点。四个留出住宅的指标差异明显；这些数值反映 Robot@Home2 当前采样和标注范围，不代表用户手机相机或机器人上的实测表现。细节见 [candidate-v3 数据与 640 基准分析](../saycheez/RobotAtHome2_candidate_v3数据与640基准实验报告.md)。

## 960 分辨率对照：部分完成，不能作最终结论

960 对照沿用四折划分、AdamW、seed、batch、patience 和其他主要训练设置，只提高输入分辨率。由于项目暂停，只有前三折完成了独立验证：

| 留出住宅 | 最佳 epoch | 独立 Recall | 独立 mAP50 | 独立 mAP50–95 | bottle AP50 |
|---|---:|---:|---:|---:|---:|
| alma | 5 | 0.1970 | 0.1787 | 0.1001 | 0.0205 |
| anto | 4 | 0.1531 | 0.0904 | 0.0320 | 0.0571 |
| pare | 7 | 0.1556 | 0.1206 | 0.0591 | 0.0111 |
| 前三折等权平均 | — | 0.1686 | 0.1299 | 0.0637 | 0.0296 |

`rx2` 折已停止在第 5 轮；本地留有 `best.pt`、`last.pt` 和训练 CSV，但尚无该折独立验证，也没有合法的四折 960 汇总。前三折均值低于已完成的 640 基线，但样本只有三折，不能用它替代完整对照或宣称最终退步。不要直接重跑原始命令：旧输出目录会被防覆盖检查拒绝；恢复时应先验证 checkpoint 和可续训状态，再决定从 rx2 接续或在新目录重训该折。

## 当前已知问题

1. **Bottle 检出能力弱、漏检风险高。** 640 四折 bottle AP50 为 0.0891、Recall 为 0.1328；960 已完成三折的 bottle AP50 均值约 0.0296。需要完成 960 四折并运行按原图框短边分层的错误审计，区分极小目标、类别混淆、定位误差和其他漏检。
2. **跨住宅表现波动。** LOHO 比随机拆分更能暴露环境差异，但当前候选数据和类别覆盖仍有限；不能只看总体均值。
3. **过拟合/泛化不足的原因未完全定位。** 当前结果说明泛化弱，但需要结合训练曲线、逐住宅误差、类别分布与标注质量分析，不能仅据低 mAP 断定原因是训练轮数或某个增强开关。
4. **当前没有全新的外部测试环境。** `sarmis` 已在早期 v2 评估中使用，不可再用于当前选模、调参或作为未触碰测试集。最终仍需收集新场景并重新标注。
5. **本地 960 折续训尚未验证。** 检查 `last.pt` 是否可读，以及 Ultralytics 是否能恢复优化器、epoch 和早停状态；若不能可靠续训，在全新输出目录单独重训 rx2。
